2. 앱에서 처리하는 정보와 목적

온보딩·설정에서 입력한 표시 이름(별명), 학습 목표와 챕터 진행, 학습·정오답·힌트 기록, 즐겨찾기, XP·Coin 및 지급·소비 기록, 캐릭터 선택·성장·먹이 상태, 앱 설정과 진행 복원에 필요한 정보를 기기 내 앱 전용 저장소에 보관합니다. 이는 학습 제공, 결과 표시, 중복 보상·소비 방지 및 재실행 복원에 사용됩니다.
표시 이름은 기기 안에서 화면 인사에 사용하며 실명 입력은 필요하지 않습니다. 앱 계정용 이메일·전화번호 입력, 광고·분석 SDK, 개발자 서버 전송 기능은 현재 소스에 없습니다. 학습 기록을 개발자 서버로 전송하거나 다른 이용자와 공유하지 않습니다. 실제 배포 빌드의 권한·SDK와 일치하는지 제출 전에 다시 확인합니다.

3. 발음 기능

단어 또는 예문 발음을 선택하면 해당 영어 텍스트를 기기에 설치된 Android TTS 음성 엔진에 전달합니다. 앱은 네트워크 연결이 필요하지 않은 영어 음성을 선택하도록 구현되어 있습니다. 마이크 녹음이나 음성 입력은 사용하지 않습니다. 외부 음성 엔진의 설치·관리와 그 서비스 자체의 정보 처리는 해당 제공자의 방침을 따릅니다.

4. 보관 기간과 삭제

기기 내 기록은 앱을 사용하는 동안 보관됩니다. Android 앱 설정에서 보카테라의 저장공간 데이터를 삭제하거나 앱을 제거하면 해당 앱의 로컬 기록이 삭제됩니다. 현재 버전은 클라우드 동기화나 개발자 서버 복원을 제공하지 않으며 Android 자동 백업은 비활성화되어 있습니다. 데이터 삭제·앱 제거는 기록을 복구할 수 없게 할 수 있으므로 주의해 주세요.
이 방침은 사용자가 원할 때의 삭제 방법을 설명하며, 운영자가 임의로 기록을 초기화한다는 뜻이 아닙니다.
